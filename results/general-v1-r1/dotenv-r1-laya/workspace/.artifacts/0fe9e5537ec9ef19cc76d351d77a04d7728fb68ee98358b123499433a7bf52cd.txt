Implement parse_env(text, defaults=None). Return a new dictionary, starting with a copy of defaults when defaults is supplied; defaults must be a dictionary. Parse each physical line independently. Ignore blank lines and lines whose first non-whitespace character is #. An optional export followed by whitespace may preced a definition. A key matches [A-Za-z_][A-Za-z0-9_]*, with optional surrounding whitespace before =. For an unquoted value, trim surrounding whitespace; an inline # starts a comment only when it is at the beginning or preceded by whitespace, so abc#123 remains part of the value. A single-quoted value preserves every character until the next single quote and a double-quoted value processes only the escapes \\, \", \\n, \\r, \\t, and \\#. After a quoted value only whitespace and an optional comment are allowed. Empty values are valid. Duplicate keys use the last definition. Any nonempty malformed line, invalid key, unknown escape, unterminated quote, or junk after a quote raises ValueError.
